# LeadLock AI
**Architecture:** Dual-stack system using FastAPI and Vite/React.
**AI Engine:** Gemini 1.5 Flash for Nigerian real estate.

---

## AI Studio Deployment
View app: https://ai.studio/apps/6b641eb7-112a-4d89-8166-aeea8478dc45

### Run Locally
1. `npm install`
2. Set `GEMINI_API_KEY` in `.env.local`
3. `npm run dev`
